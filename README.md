# Prospectus Pro v2

Prototype PWA de gestion de tournées de distribution.

Fonctions incluses:
- tournée rapide avec bouton maison suivante;
- validation "Distribué" ou "Absent — repasser";
- historique de chaque passage;
- carte GPS et navigation;
- import CSV d'adresses;
- modèle CSV;
- secteurs et distributeurs;
- statistiques;
- sauvegarde JSON;
- installation PWA.

Important : cette version fonctionne localement sur l'appareil. La synchronisation multi-téléphones et le compte administrateur nécessitent un serveur/base de données, qui constituent l'étape suivante pour une version commerciale.
